## Selected release processing record

- Source: João Alves, _Recyclable Waste Image Dataset_, Mendeley Data V1, DOI `10.17632/h5pxbsdz4m.1`, CC BY 4.0. Attribution is retained in the local source manifest and `ATTRIBUTION.txt`.
- Rights check: publisher dataset page, version metadata and its author-collected-only description were checked before download. The CC BY 4.0 legal code requires attribution and notes a licensor can only grant rights they hold; source content still warrants respect for the publisher's third-party restriction.
- Retrieval: publisher API metadata and individual public file downloads, 2026-10-08. The program rejects changed license/provenance text, files over the size guard, and any size or checksum mismatch.
- Publisher-reported classes: Cardboard 432, Glass 49, Metal 95, Paper 98, Plastic 315. These sum to 989, not the title/description's 1,000. No missing labels or samples are synthesized.
- Processing: 977 files accepted; 12 exact decoded duplicates removed; zero decode failures; no unsupported or conflicting labels. Cleaned split: train 620, validation 108, test 249. The smaller publisher source group `CWMF` was held out entirely for test; `UHW` was stratified by material into training and validation. Test coverage has no Glass examples (CWMF has no Glass samples), and just four Paper examples. These gaps make the scores incomplete and should be treated cautiously.
- Model selection: CPU k-nearest-neighbors over normalized RGB histograms, grayscale thumbnail and difference-hash features. `k=3` was selected among 1/3/5 by validation macro-F1 (30.73%). Validation accuracy was 41.67% (108 images).
- Held-out test: 45.38% accuracy on 249 CWMF images; macro precision 29.93%, macro recall 31.49%, macro-F1 28.15% averaged only over the four classes with test support (Cardboard, Metal, Paper, Plastic). Glass is explicitly unrepresented in test and has null class metrics. These low results and coverage gaps are not production-ready; model predictions are not integrated into scans and must not inform disposal or impact claims. Exact confusion matrices and per-class values are in the local, gitignored `data/processed/recyclable-waste-mendeley-v1/evaluation.json`.

## Intake and evaluation controls

- Before any future dataset download, save the upstream license and terms, dataset version, retrieval date, archive hash, per-image rights records where applicable, citation and allowed usage.
- Exclude data lacking commercial-use rights, attribution requirements that cannot be preserved, or permission to use for model training. Do not infer consent from a public URL.
- Keep raw downloads read-only and outside Git. Record exact file counts, byte sizes, image decode failures, class counts, duplicates, near-duplicates and provenance before any relabeling.
- The local split manifest records a deterministic seed and holds one publisher source group out entirely for test. The remaining group is stratified into training and validation by material. Session IDs were unavailable, so related views may still appear in train/validation; the source-level holdout does not resolve all possible near-duplicate or acquisition bias.
- Map source labels conservatively into Waste2Watt categories. Ambiguous, mixed and unsupported labels remain excluded or explicitly unknown; do not fabricate labels or balance classes by duplicating images.
- No TrashNet, TrashNet++, TACO or RealWaste imagery is in the pipeline. The selected Mendeley set was used only for a local reproducible research benchmark, not as a representative field test or operational classifier. The model and cleaned images are excluded from Git.
