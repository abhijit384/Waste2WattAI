## Implementation

`services/analysis/src/waste2watt_analysis` contains image decoding, classification parsing, deterministic recovery, factor calculations and task orchestration. Runtime dependencies are pinned; `scripts/prepare-analysis.ps1` stages Python 3.12 Linux x86_64 wheels on E: for the Lambda. The first deployed package failed at import because `typing_extensions` was omitted. The dependency is explicitly pinned and packaging checks require it. The repair was deployed to the existing analysis Lambda; a safe Lambda `HealthCheck` now returns `READY` with inference disabled. This verifies imports/startup only, not S3 processing or a Step Functions upload execution.

PNG/JPEG/WebP are signature-checked, decoded twice (verification then pixel load), limited to 10 MiB and 20 million pixels, and animated images rejected. EXIF orientation is applied, metadata discarded, and a fresh JPEG of at most 1024×1024 and 3 MB is submitted. The exact S3 version from the event must match the scan's private owner/scan/upload key, MIME and byte count. Ownership derives from the persisted Cognito-owned scan, never from a new browser-supplied owner. The inference role can read only `private/*` in the existing bucket; no public image URL is created.

Reference: [Nova request schema](https://docs.aws.amazon.com/nova/latest/userguide/complete-request-schema.html), [image input guidance](https://docs.aws.amazon.com/nova/latest/userguide/modalities-image.html).

The tool envelope `record_classification` is data only. Exactly one matching envelope and `tool_use` termination are required. Unknown categories, extra properties, truncated responses and missing fields fail closed. Shared Zod schemas are exported to committed JSON Schema for Python jsonschema validation; a regression test detects drift. Semantic checks enforce category/outcome agreement and low-confidence review. Raw model text is never executed, used to select tools, or treated as AWS instructions.

Nine categories and explicit no-waste, low-confidence, multiple-material, invalid-image and unavailable outcomes are supported. Confidence bands are qualitative, percentages and photographic weight are prohibited, and proportions remain null. The user's supplied kg quantity is preserved. A model cannot reliably establish hazard absence, composition, recyclability or plant acceptance; human review remains necessary.
